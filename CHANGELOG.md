## [1.0.0] — 2026-08-14

Перший стабільний реліз. Пройдено аудит безпеки й перевірку готовності до
production.

### Платформа

- **Бекенд** — FastAPI + PostgreSQL 16 + Redis 7, 135 маршрутів, 388 тестів.
- **Android-агент** — Kotlin, foreground service, ідентичність на EC P-256
  в Android Keystore (StrongBox/TEE за наявності).
- **Панель** — React 18 + TypeScript + Vite.
- **Розгортання** — Docker Compose з TLS-термінацією в nginx.

### Модулі

- Реєстрація пристроїв за одноразовими токенами (QR або вручну).
- Телеметрія й моніторинг: правила алертів, історія показників.
- Репозиторій APK: розбір `AndroidManifest.xml` без зовнішніх залежностей,
  дедуплікація за SHA-256, політика підпису.
- Файловий модуль: доступ лише до каталогів з allowlist, відновлювані передачі.
- Геолокація — **opt-in**, вимкнена за замовчуванням.
- Віддалена підтримка — показ екрана лише після явної згоди користувача
  (`MediaProjection` + системний індикатор), керування лише через
  `AccessibilityService`, увімкнену самим користувачем.
- Реєстр команд — закритий перелік дій із конфігурованими дозволами;
  віддаленої оболонки в системі немає.
- Комунікаційний модуль (SMS / журнал дзвінків) — **opt-in**, вимкнений за
  замовчуванням, із шифруванням даних at rest.

### Безпека

- JWT з ротацією refresh-токенів; refresh живе лише в `HttpOnly`-cookie,
  захист CSRF за схемою double-submit.
- Миттєве відкликання access-токенів (`sessions_valid_from`) — вихід, зміна
  пароля чи ролі діють одразу, а не за 15 хвилин.
- RBAC із чотирма ролями; матриця дозволів в одному місці.
- Ротація ключів пристроїв: нову пару створює агент, підтверджуючи підписом
  старого ключа; приватна частина не залишає Keystore.
- Ротація серверних секретів без розриву сесій (`*_PREVIOUS`, `TOKEN_EPOCH`).
- Шифрування чутливих даних at rest — AES-256-GCM, ключ в оточенні, не в БД.
- Аудит усіх адміністративних дій, зокрема перегляду особистих даних.
- Rate limiting на весь API, CSP і повний набір заголовків безпеки.
- Роль БД для застосунку без права DDL; міграції — окремою роллю.
- Контейнери: `no-new-privileges`, `cap_drop ALL`, `read_only` для API.

### Експлуатація

- `start-backend.bat` — налаштування й запуск бекенду одним файлом (Windows).
- `make backup` / `make restore` — резервне копіювання БД і сховища.
- [Посібник із розгортання](docs/DEPLOYMENT.md): TLS через Let's Encrypt,
  Device Owner, моніторинг, оновлення.

### Прозорість

Агент завжди видимий: іконка в лаунчері, постійне сповіщення, екран стану.
Прихованого збору даних, віддаленої оболонки й обходу дозволів Android у
системі немає — і це перевіряється тестами.

### Відомі обмеження

- Перезавантаження й тихе встановлення потребують режиму Device Owner.
- Запис розмов, перехоплення повідомлень чужих застосунків, кейлогінг і
  читання сповіщень задля вмісту не реалізовані: таких API Android
  застосунку не надає. Обходити обмеження ми не намагаємось.
- MMS не збираються (лише SMS).
- Пакетної видачі команд на групу пристроїв і планувальника немає.
- Docker Compose розрахований на одну машину; HA-конфігурації немає.
- Для кількох реплік API потрібна липка маршрутизація `/ws/support/`.
